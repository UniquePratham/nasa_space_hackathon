# nasa_space_hackathon

NASA Space Apps hackathon build - interactive 3D visualisation with React Three Fiber.

NASA Space Apps hackathon entry. The 3D scene is built with React Three Fiber.

## Stack

- JavaScript
- Next.js
- Chakra UI
- React Three Fiber
- Framer Motion

## Getting started

```bash
npm install
npm run dev
```
